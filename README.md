

\# Tool-Using AI Research Agent



An AI research agent for software engineering technology research.



\## Project Goals

\- Research and compare software technologies.

\- Search and collect information from reliable sources.

\- Extract and validate relevant information.

\- Maintain source references.

\- Generate structured, evidence-based reports.



\## Tech Stack

\- python 3.11

\- LangGraph

\- LangChain

\- GapGPT API

\- Jupyter Notebook
